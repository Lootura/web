Proceso para validar un medio

  1. 1.Abrir la web y confirmar que es un medio real, actualizado y alineado con el tono de Lootura.
  2. 2.Revisar los ultimos titulares del RSS: deben ser noticias o analisis utiles, no promociones, listicles vacios ni ruido evergreen.
  3. 3.Comprobar que aporta cobertura nueva frente a las fuentes activas: region, categoria, especializacion o mirada editorial.
  4. 4.Evitar duplicados fuertes de agencias o medios ya cubiertos; si solo replica lo mismo, no mejora el feed.
  5. 5.Preferir feeds con resumen, fecha clara, enlaces estables y suficiente actividad reciente.
  6. 6.Copiar el draft solo si pasa la revision, pegarlo en el data/feeds.<perfil>.json correspondiente y mantener status draft.
  7. 7.Ejecutar npm run news:update:<perfil> y revisar /admin/processes antes de considerarla estable.

Ejecucion local

Esta pagina no lanza el scouting desde el navegador. Copia el comando, ejecutalo en terminal y refresca esta vista.

npm run sources:scout

Regla de producto

No se anade una fuente porque exista RSS. Se anade solo si hace el feed mas claro, mas fresco o menos ciego sin volverlo mas ruidoso.

Promocion

El boton copia un objeto draft. La escritura final en `data/feeds.*.json` sigue siendo una decision manual.

Weight

Se lee como prioridad editorial sobre 5. Una fuente nueva suele empezar en 1/5 o 2/5 aunque sea buena.
